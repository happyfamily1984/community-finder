# 커뮤니티 파인더 (안드로이드 앱)

국내 주요 커뮤니티의 베스트·인기글을 **화제도순으로 한곳에 모아 보여주고**, 새 화제글이 뜨면 **휴대폰 알림**을 띄워주는 안드로이드 앱입니다.
PC를 켜둘 필요 없이 **수집은 클라우드(GitHub Actions)** 에서 돌아갑니다.

```
 GitHub Actions (10분마다)                       안드로이드 앱 (APK)
 ┌───────────────────────────┐   posts.json   ┌──────────────────────────────┐
 │ 7개 커뮤니티 베스트 수집   │ ─────────────▶ │ 목록 · 필터 · 정렬 · 검색      │
 │ 화제도·급상승 계산         │  (data 브랜치)  │ 백그라운드 15분마다 확인 → 알림 │
 └───────────────────────────┘                └──────────────────────────────┘
```

## 설치
[Releases](../../releases/latest)에서 `community-finder.apk`를 휴대폰으로 받아 설치하세요. ("출처를 알 수 없는 앱 설치" 허용 필요)
앱 실행 → 🔔 → 알림 켜기.

## 지원 커뮤니티
디시인사이드(실베) · 더쿠(HOT) · 루리웹(유머 베스트) · 클리앙(모공 추천) · 네이트판(랭킹) · 보배드림(베스트) — 클라우드 수집
에펨코리아(포텐) — **휴대폰에서 직접 수집**. 에펨코리아는 클라우드(데이터센터) 접근을 HTTP 430으로 막기 때문에,
앱이 15분에 한 번 `/best` 한 페이지만 받아오고 429/430 응답 시 Retry-After(기본 30분) 동안 쉽니다. 설정에서 끌 수 있습니다.
수집 규칙은 `src/sources.js` (URL + CSS 선택자). 수집 실패한 곳은 앱에 ⚠ 로 표시됩니다.

## 화제도 (0~100)
같은 커뮤니티 안에서의 조회·댓글·추천 **백분위 평균(85점)** + 분당 조회수 증가 **급상승(15점)**.
커뮤니티마다 규모가 달라도 공정하게 비교됩니다.

## 알림
- 새로 베스트에 오른 글 중 **화제도 기준점 이상** 또는 **키워드 포함**
- 알림 받을 커뮤니티 선택, 확인 주기 15/30/60분
- 안드로이드 정책상 백그라운드 확인은 최소 15분 간격이며, 절전 모드에서는 늦어질 수 있습니다.

## 클라우드 구성
| 워크플로 | 하는 일 |
|---|---|
| `.github/workflows/crawl.yml` | 10분마다 수집 → `data` 브랜치에 `posts.json` 게시 (앱이 `raw.githubusercontent.com`에서 받아감) |
| `.github/workflows/android.yml` | `android/` 변경 시 테스트·스크린샷·APK 빌드 → Releases 게시 |

- 공개 저장소라 GitHub Actions 사용료가 없습니다.
- GitHub는 **60일간 저장소 활동이 없으면 예약 워크플로를 자동 중지**합니다. 멈추면 Actions 탭에서 다시 켜세요.
- 저장소를 포크했다면 앱 설정 > 고급에서 피드 주소를 바꾸거나, 빌드 시 `FEED_URL` 환경 변수를 지정하세요.

## 개발
```bash
npm ci && npm test          # 수집기 테스트
npm run crawl:demo          # 가짜 데이터로 out/posts.json 생성
cd android && ./gradlew assembleRelease   # APK (Android SDK 필요)
```
`android/app/community-finder.keystore`는 어디서 빌드해도 같은 서명이 되도록 저장소에 넣은 공용 키입니다(덮어쓰기 업데이트용). 플레이스토어 배포에는 별도 키를 쓰세요.
