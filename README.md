# 커뮤니티 파인더

국내 주요 커뮤니티의 **베스트·인기글을 한곳에 모아 화제도순으로 보여주고**, 새 화제글이 올라오면 **푸시 알림**을 보내주는 앱입니다.
웹앱(PWA)이라 휴대폰에서 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

## 지원 커뮤니티
디시인사이드(실베) · 에펨코리아(포텐) · 더쿠(HOT) · 루리웹(유머 베스트) · 클리앙(모공 추천) · 네이트판(랭킹) · 보배드림(베스트)

추가하거나 고치려면 `src/sources.js`에 URL과 CSS 선택자만 적으면 됩니다. 사이트 구조가 바뀌어 수집이 실패하면 화면 상단 칩이 흐리게 표시되고 서버 로그에 이유가 나옵니다.

## 실행
```bash
npm install
npm start          # http://localhost:3000  (3분마다 수집)
npm run demo       # 실제 사이트 접속 없이 가짜 데이터로 화면·알림 확인
npm test
```
환경 변수: `PORT`, `CRAWL_INTERVAL_MIN`(수집 주기, 분), `VAPID_CONTACT`(예: `mailto:me@example.com`)

## 화제도 점수 (0~100)
커뮤니티마다 조회수 규모가 달라서, **같은 커뮤니티 안에서의 백분위**(조회수·댓글·추천)를 평균해 85점 만점으로 만들고,
직전 수집 대비 **분당 조회수 증가(급상승)** 를 15점 만점으로 더합니다.

## 알림
🔔 버튼 → 알림 켜기. 조건:
- 새로 베스트에 오른 글 중 **화제도 기준점 이상**, 또는
- 제목에 **키워드**가 들어간 글 (점수 무관)
- 알림 받을 커뮤니티 선택 가능

앱을 닫아도 브라우저가 살아 있으면 알림이 옵니다(Web Push). 푸시는 `localhost` 또는 **HTTPS**에서만 동작하므로, 휴대폰에서 쓰려면 HTTPS 서버에 올려야 합니다.
iPhone은 iOS 16.4+ Safari에서 홈 화면에 추가한 뒤 그 앱에서 알림을 켜야 합니다.

## 구조
```
src/sources.js   커뮤니티 목록·선택자
src/fetcher.js   HTML 가져오기 (EUC-KR 자동 변환)
src/parser.js    선택자 기반 목록 파싱
src/score.js     화제도 계산
src/crawler.js   주기적 수집, 신규/급상승 감지, data/posts.json 저장
src/push.js      Web Push (VAPID 키 자동 생성, 구독별 알림 조건)
src/server.js    API + 정적 파일 서버
public/          PWA 화면, 서비스 워커
```

## 주의
각 사이트의 이용약관과 robots.txt를 확인하고, 수집 주기를 너무 짧게 잡지 마세요. 글 본문은 저장하지 않고 제목·링크·숫자만 가져오며, 클릭하면 원본 사이트로 이동합니다.
